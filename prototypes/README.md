# Mixcat 原型归档

这里保存用于讨论和验证的原型，不作为正式客户端实现。正式设计见 [docs/design](../docs/design/README.md)。

| 目录 | 内容 |
| --- | --- |
| [desktop](desktop/README.md) | 桌面功能验证原型的源码、既有测试、启动配置、依赖清单和构建快照。 |
| [ui](ui/README.md) | 极简及像素元素版界面图片、静态页面，以及早期工作台方案。 |

归档未搬迁真实项目数据、登录信息或历史会话，也未启动或重建客户端。`.runtime/` 中的历史实验和临时材料仍保留原位；正式文档只将它们作为限定范围的观察依据。
