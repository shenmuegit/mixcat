# Mixcat 界面原型

这些图片与静态页面用于确认布局和视觉方向，内容为示例，不代表对应功能已完成。

当前方向为极简工作空间：左侧“项目／笔记／知识库”，项目页中间展示卡片，点击卡片进入工作流。像素元素仅用于标识、图标、状态和选中细节，正文保持易读。

浏览器 profile、测试截图缓存及失败的渲染实验没有混入此归档。功能要求以 [正式设计文档](../../docs/design/README.md) 为准。
