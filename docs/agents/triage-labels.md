# Triage labels

Use the default Matt Pocock triage roles for this repository.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| bug | `bug` | Existing behavior is broken |
| enhancement | `enhancement` | A feature or behavior improvement |
| needs-triage | `needs-triage` | Evaluation in progress |
| needs-info | `needs-info` | Necessary information is missing |
| ready-for-agent | `ready-for-agent` | Verified and specified for implementation |
| ready-for-human | `ready-for-human` | Requires a human decision or implementation |
| wontfix | `wontfix` | Will not be implemented |

Each triaged Issue has one category and one state. Replace the previous state label when transitioning. Verify labels exist in GitHub before applying them; create a missing configured label when first needed. This file defines the vocabulary and does not claim the remote labels have already been created.

The repository owner has authorized verified, in-scope feedback to proceed automatically as described in [AGENTS.md](../../AGENTS.md). Do not introduce repeated routine approval steps. Preserve the triage skill's required disclosure on content it publishes.
