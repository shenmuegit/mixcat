# Issue #114 实施计划：Codex 目标与结果卡片

规格：[个人信息流](../design/2026-10-29-personal-information-feed.md)。

原 Tasks 1–8 的存储、原生线程、调度与可靠性实现仍可复用，但旧资料管理界面及其验收不再代表最终产品。当前修正起点 5e45335dd75866fd35897ab8fd19df48b9ffb1bf。

## Global Constraints

- 首版只支持文本，暂不做项目关联。
- 每个采集任务是独立 Codex 会话；由对话形成目标和定时计划。
- 信息流只提供一个结果输出工具；客户端持久化计划并到点唤醒会话。
- 首页参考项目卡片；详情阅读结果并继续对话。删除旧资料管理工作台。
- 保留已有数据、身份校验、持久回执、未知派发保护与草稿恢复。
- 工作数据位于项目内部；一项实现后独立复核，最终两轴审查与实际 main 重启。
- Computer Use 仅在必要的短时操作中使用，操作结束立即终止并释放控制。

## Task 10: 对话目标计划与唯一输出工具

复用 FeedEngine 的调度、事务与恢复；新增固定目标文件的受限导入，在成功完成/成功核对时统一应用。创建允许 message 初始输入，prompt 先沟通目标、用原生文件能力管理计划，定时运行才按目标执行。只保留 save_feed_result 工具。补工具目录、身份/回执、目标文件原子应用/恢复/拒绝输入等真实边界测试。当前已保存数据可继续读取。

## Task 11: 卡片与结果/对话详情

## Task 12: 集成验收
