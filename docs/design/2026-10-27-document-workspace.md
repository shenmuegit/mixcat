# 文档工作区与实时预览编辑

关联 [Issue #35](https://github.com/shenmuegit/mixcat/issues/35)，基线 `810678f`。用户明确提出八项文档工作区调整，并选择 Grove 式实时预览编辑。

## 需求与边界

1. 同目录文件按时间倒序；执行选择为真实文件修改时间，缺失／无法读取时回退管理记录更新时间。同一时间按路径稳定排序，文件夹仍先于文件。
2. 文件树主行显示文档名称，次行显示文件名；展开、选中、草稿和引用身份仍由原文档 ID 驱动。
3. 文件树与正文、大纲与正文的分隔边可左右拖动，也能用方向键调整。按后续 [Issue #55](https://github.com/shenmuegit/mixcat/issues/55)，文件树下限由搜索框与操作按钮单行所需的实际宽度决定（不低于 160px），常规最大 460px；大纲最小 160px、最大 360px；正文至少 280px。窗口缩小时收敛到可用宽度。宽度在当前项目的视图／文档切换中保留。搜索和操作等高且不换行；搜索、目录与大纲区域使用白底，文档页签下方不显示分隔线。
4. 文档内容工具栏不显示 D 编号，页面工具栏不显示左上“文档”标题。
5. 移除“纳入已有文档”按钮及其前端草稿分支，自动发现和节点注册能力继续由现有服务负责。
6. 阅读正文不显示路径。文件位置、移动和缺失文件重新关联放入折叠区；删除／恢复的冲突说明仍须给出相关文件位置。
7. 采用用户确认的实时预览：非活动 Markdown 块渲染为正文，当前编辑块显示源文。标题与正文处于同一内容画布，编辑／阅读按钮带有文字和图标。
8. 切回阅读前保存当前内容，成功后才切换；失败／冲突停留编辑并保留草稿。快捷键保存可留在编辑状态。尚未完成的文件移动不能被误报成全部已保存。

按后续 [Issue #74](https://github.com/shenmuegit/mixcat/issues/74)，目录分隔线从搜索工具栏底部开始；有溢出内容时，同一条线上显示目录滚动滑块。上下拖动滑块滚动目录，左右拖动调整栏宽，以起手方向锁定本次操作。滑块支持上下方向键、PageUp/PageDown、Home/End，原分隔线的键盘调宽继续可用。搜索、折叠和窗口变化同步滑块；无溢出时隐藏。正文和大纲继续隐藏原生滚动条。

范围为现有文档工作区。Todo 和 Issue 使用原有表单；本次基线已包含 Issue 表格视图。Grove 仅为只读参考，不修改或启动它。上传、媒体导入、知识图谱、分析功能和新的工作流派发规则不在本次范围内。

## 参考与实现选择

参考 Grove 的 `DocumentEditorPane`、`MarkdownDocument`、`DocumentResizeHandle`、`live-preview` 和模式切换：轻量工具栏、无框标题、同位置内容、当前块编辑以及切回阅读前保存。

考虑过仅调整 textarea 排版，但用户已明确选择实时预览；完整复制 Grove 编辑器会带入媒体、表格单元格编辑和分析定位等额外功能。采用 CodeMirror 的 Markdown 解析与编辑能力实现当前块切换，复用 Mixcat 的安全 Markdown 渲染器和引用服务。这是执行者的实现选择，不将额外功能冒认为用户要求。

通过官方 npm 流程加入 CodeMirror state/view/commands/autocomplete/lang-markdown，版本参考 Grove 已使用的版本。支持正文编辑、撤销／重做、中文输入、常用 Markdown 块和 @ 补全。使用同一渲染规则呈现阅读与非活动编辑块；原始 HTML 和不安全链接仍受现有策略约束。块级预览需携带整篇文档的引用定义，避免标准 Markdown 引用链接失效。

## 数据与保存

- 正文仍存于真实 Markdown 文件。文件修改时间作为查询元信息返回，不因读取时间而改写管理记录或产生修订。
- 文档树使用 `fileModifiedAt ?? updatedAt` 排序；管理身份、文件哈希、版本冲突和恢复日志沿用现有服务。
- 原有逐文档 Draft 是唯一未保存内容来源。新编辑器通过受控值回传修改，不建立第二个持久化层。
- 阅读／编辑共用内容容器和排版；切换保存滚动位置，编辑器重测布局后恢复。模式切换不允许悄悄丢弃文本或覆盖外部修改。
- 新文档默认由现有服务生成 `docs/document-N.md`，可在折叠文件操作里指定路径。路径调整沿用明确的移动／重新关联动作。
- 文档编号仍用于 @ 引用和稳定 ID，不在被要求精简的文档内容工具栏中展示。

## 验收

用公开管理命令和真实文件修改时间验证排序元信息；用渲染和 Electron 交互验证主次行、同目录排序、两条分隔边、窗口变化、编号／标题／路径／入口移除。

真实编辑回归覆盖中文与段落输入、Markdown 块预览、跨块引用定义、@ 插入与跳转、撤销／重做、模式切换位置、草稿切换和保存冲突。既有文档生命周期、Issue 表格和 Todo 派发检查继续执行。最终运行完整测试、两轴审查，合并后构建并重启实际客户端。
