## Mixcat 共用视觉约定

现有工作台以横向空间、操作优先级、长任务可读性及 Windows 键盘行为为基线。下表给出逐项方案共用的初始规格，具体条目写明它在实际页面中的尺寸、状态和例外。

| 项目 | 共用设计 |
| --- | --- |
| 可用空间 | 以 `1100×720`、`1280×800`、`1460×960` 和 125% 缩放核验。节点详情从现有 420 px 宽开始，最窄 320 px，画布尽量保留约 270 px。优先让正文换行、把次级操作收纳到菜单或将多栏改为单栏。 |
| 密度与层级 | 间距以 4、8、12、16、24 px 为主。正文 14/22 px，元信息 12/18 px，面板标题 16/24 px，页标题 24/32 px。保留系统中文字体和现有代码/编号样式。 |
| 主题 | 沿用浅色、深色和紫色主题的现有变量。页面用 `--theme-surface`，导航和独立面板用 `--theme-sidebar`，层级用一像素 `--theme-line` 与间距。选择、焦点、失败、警告和成功分别取对应语义变量，且保留文字、图标或线型提示。 |
| 按钮 | 常规命中区至少 32×32 px，紧凑行至少 24×24 px。主动作保留清楚的动词，次级操作使用现有描边按钮、文字或带可访问名称的图标。键盘焦点清晰可见，正文对比目标 4.5:1，必要控件边界及焦点目标 3:1。 |
| 动效 | 常规按钮反馈使用 100–160 ms，弹层或需要维持空间关系的过渡使用 140–200 ms。优先使用颜色、透明度或小幅位移。减弱动态下保留可读状态。队列、核对、失败等数值即时使用已确认数据。 |
| 数据状态 | 用对象身份和当前回执驱动显示，零、空列表、无匹配、尚未确认及失败各能读懂。来自不同项目的草稿、运行、附件与查询继续隔离。图表的时间、单位、数据窗口和明细表使用同一口径。 |

实际走常用入口验收。项目首页与设置从应用壳进入，节点会话从工作流或 ComfyUI 的共有面板进入，Issue 和文档从项目管理进入，信息流成果从采集详情进入。模板和图表的样例绑定可追溯的固定数据。 [应用壳](../../src/renderer/App.tsx) · [节点会话](../../src/renderer/SessionPane.tsx) · [项目管理](../../src/renderer/ProjectManagement.tsx) · [文档树](../../src/renderer/DocumentTree.tsx) · [信息流](../../src/renderer/FeedWorkspace.tsx) · [ComfyUI](../../src/renderer/ComfyWorkspace.tsx) · [主题样式](../../src/renderer/theme.css)

会话继续使用实际节点、线程和轮次。用户处于原生输入法组合状态时保留现有键盘语义。独立的技术回放可检查加载和回执，但正式界面验收要落到真实入口。人工单选仍点击即答，自由填写仍明确提交。Issue 树的父子关系、历史状态、派发和保存保护沿用现有约定。信息流计划由已有采集会话制定，手工和跨采集排期的设计采用样例。 [会话工作台](2026-10-19-session-workbench-design.md) · [人工核对](2026-10-22-human-review-design.md) · [统一 Issue](2026-10-29-unified-issues.md) · [个人信息流](2026-10-29-personal-information-feed.md) · [模板能力](2026-11-06-template-capability-setup.md)

## 可视基础（6 项）

#### 005 theme

**语义色、圆角与阴影** · 接入 · [固定源码](https://github.com/BoardUI/boardui/blob/ec5c5eb3e29c2441be63b9422cd54f411ef23466/styles/theme.css)

- **BoardUI 原样**　BoardUI 用浅色和暗色共用一套文字、背景、边框和状态角色。蓝色强调色贯穿主操作、选中、焦点和图表亮点。普通卡片靠浅阴影分层，菜单单有较深阴影，颜色与圆角和阴影各有可替换的值。
- **Mixcat 页面**　设置 → 外观，先在项目列表、节点会话和 Issue 筛选复用同一视觉语言
- **布局**　按桌面壳、侧栏和内容分三层。浅色窗口轨道保留 #f3f3f5，侧栏用白色，正文用 #fafafa。列表行间用 1 px 分隔，只有盖到别的内容上的菜单增加阴影。
- **按钮与操作**　浅色、深色、紫色三项作为一组，当前项同时有描边和选中语义。正文每组只保留一个主按钮，关闭、更多与次要动作使用文字或图标。
- **样式**　直接映射已有 theme-surface、theme-sidebar、theme-line 与 theme-text。强调色用于焦点和选中，警告与失败用现有状态色并有读得出的文字。普通输入圆角 6 px，浮层圆角 10 px。
- **动效**　切换主题后一次应用正文、侧栏与浮层的变量。保留焦点、草稿、滚动位置。控件悬停色用 120 ms 过渡，主题切换和减弱动态状态直接生效。
- **验收**　浅色、深色、紫色逐个切换。检查同一行焦点的清晰边界及警告文字，节点画布与打开的 CodeMirror 仍可输入和滚动。
- **#291 已有证据**　相邻改动。新增工作台样式使用现有主题变量，语义色与三主题仍来自原主题系统。 [Workbench.css（#292）](https://github.com/shenmuegit/mixcat/blob/2f161fddf6446960d21da0a810103ae8cb4c4d4f/src/renderer/Workbench.css)

#### 006 typography

**文字层级** · 接入 · [固定源码](https://github.com/BoardUI/boardui/blob/ec5c5eb3e29c2441be63b9422cd54f411ef23466/styles/typography.css)

- **BoardUI 原样**　BoardUI 的 Inter 字阶从展示标题到小字使用组合样式，每档把字号、行高、字距、字重绑在一起。例如 24/34 标题、20/26 小标题和 16/22 标题档都有 400–700 字重可选。
- **Mixcat 页面**　工作流 → 节点会话，项目 → Issue 树表，新建项目模板卡
- **布局**　页标题占首行，面板标题与控制同行，内容从固定左右边距对齐。狭窄栏让节点名或 Issue 标题换行，编号和更新时间在紧随的元信息行。
- **按钮与操作**　短按钮名保持 14/20，明确主动作加到 600 字重。长动作给悬停和键盘都可读的名称，在窄栏允许换行或由相邻详情完整展示。
- **样式**　沿用 Windows 系统字体与中文回退。页标题 24/32、面板标题 16/24 600、消息正文 14/22、表头及元信息 12/18。编号、代码和时间使用等宽或等宽数字。
- **动效**　字号和行高固定，筛选、续接、加载或主题切换时仅更新文本与状态色，保持文字基线和行占位。
- **验收**　在 320 px 节点栏和 125% 缩放下读长中文标题、英文路径、多行正文与代码。主要操作和状态保持可读，复制路径得到完整原文。
- **#291 已有证据**　相邻改动。调整了模板与会话的局部字号和信息层级，文档及对话的全部排版未在该差异中统一。 [Workbench.css（#292）](https://github.com/shenmuegit/mixcat/blob/2f161fddf6446960d21da0a810103ae8cb4c4d4f/src/renderer/Workbench.css)

#### 007 globals

**全局样式** · 接入 · [固定源码](https://github.com/BoardUI/boardui/blob/ec5c5eb3e29c2441be63b9422cd54f411ef23466/styles/globals.css)

- **BoardUI 原样**　BoardUI 的全局 CSS 定义浅深底色、主题下的标识和阴影、表面交界、表单默认样式。公开样式还包含约 3.4 s 的进度文字扫光、数字变化时 220 ms 淡入、减弱动态分支和主题揭幕的全局配合。
- **Mixcat 页面**　Mixcat 应用壳及工作流 → 节点会话 → 当前任务提示，模板能力准备 → 进度行
- **布局**　窗口壳先给统一页面底色、默认字体和表单间隔。当前执行提示保留 24 px 行高，每个模板进度行的高度一致。编辑器、画布和嵌入面板各在自己的内容区。
- **按钮与操作**　按钮、输入、裸链接按真实职责提供焦点态。外观设置沿用原入口，减少动态采用系统偏好。已禁用或正提交的按钮同时有文字和原语义。
- **样式**　全局只设置基础文字及配色。组件的边框、输入选择和动画使用局部类。模板准备延用 theme-muted 文字及语义色，React Flow、CodeMirror、Excalidraw 自身样式独立。
- **动效**　共享过渡用于前景控件的 120 ms 颜色切换。对当前阶段最多做一次 140 ms 透明度变化，历史、错误和后台任务保持稳定。减少动态直接进入结果。
- **验收**　保持一个文档在编辑状态，同时切主题并观察前景真实任务。标题没有闪屏，画布可拖、编辑器光标可见，后台节点与历史记录保持静态。

#### 011 scroll-fade

**滚动边缘提示** · 接入 · [免费注册表源码](https://www.boardui.com/r/scroll-fade.json)

- **BoardUI 原样**　BoardUI 在纵向滚动区域顶部覆盖 24 px 的渐隐，内容从固定标题下滑过时可见。原实现叠一层 1 px 背景模糊、一层靠顶的 4 px 模糊与面色渐变，随着滚过最初 24 px 从透明变为可见。
- **Mixcat 页面**　工作流 → 节点详情 → 会话消息顶部，信息流 → 执行结果抽屉的成果列表
- **布局**　顶栏固定。淡化区放在独立滚动容器的顶部，覆盖在消息或成果行之上，宽度等于该容器。起始 0 px 处留普通边界，宽窄栏保持相同高度。
- **按钮与操作**　覆盖层跳过键盘焦点和鼠标事件。页面里的「回到最新」或成果返回按钮继续可按，键盘滚动在当前列表生效。
- **样式**　用 24 px 同表面色的透明度渐变和 1 px 边线，保持标题底和列表当前主题连续。只在最靠近标题一段有淡化，状态文字与焦点描边保持清晰。
- **动效**　跟着 scrollTop 从 0 到 24 px 平滑变深，停滚即稳定。减少动态时用滚离顶端后立即出现的细线提示。
- **验收**　用鼠标和 Page Down 向下滚，再回到首条。检查顶部提示随滚动出现和消失，第一行焦点及链接仍可读可点。横向页签焦点继续按 055 校验。

#### 013 chevrons

**展开与排序箭头** · 接入 · [固定源码](https://github.com/BoardUI/boardui/blob/ec5c5eb3e29c2441be63b9422cd54f411ef23466/components/foundations/icons/chevrons.tsx)

- **BoardUI 原样**　BoardUI 提供不同尺寸与语义的圆头箭头。下拉使用 16×16、2 px 线宽的下箭头，面包屑是 12×12、1.5 px 的右箭头，切换账户可用上下叠放箭头，表头排序则是填充小三角。
- **Mixcat 页面**　项目 → 文档树、Issue 表头及面包屑，工作流 → 节点配置 → 模型与选项
- **布局**　树箭头单占 16 px 图标位并按层级缩进，面包屑 12 px 分隔符位于两段文字之间，排序指示贴标题右侧固定图标位。不可选择时保留位置避免跳动。
- **按钮与操作**　树节点展开由行内按钮或键盘触发，选单箭头属于触发器，排序箭头属于表头按钮。可访问名称分别说出展开、选项菜单与排序状态。
- **样式**　沿用 Mixcat Icon 的轮廓和 currentColor。路径分隔符用次级色，活动排序与选中使用强调色。箭头尺寸独立于至少 32 px 的交互范围，紧凑行可用 24 px。
- **动效**　树展开箭头可在 120 ms 内转四分之一圈。排序按方向直接换图形，面包屑静止。开启减弱动态后树箭头同步切换。
- **验收**　打开深层目录、模型下拉及升降序表头。三类箭头的形状和反馈各有明确含义。焦点在触发器，按 Escape 退出选单后回到该触发器。

#### 014 logo

**品牌标识占位** · 参考 · [固定源码](https://github.com/BoardUI/boardui/blob/ec5c5eb3e29c2441be63b9422cd54f411ef23466/components/foundations/brand/logo.tsx)

- **BoardUI 原样**　BoardUI 标志以正方形品牌图片呈现，常用 24、32、40 px，默认 32 px。单色样式按明暗主题显示不同图片，图像预留相同尺寸以免切换时挪位。
- **Mixcat 页面**　Mixcat → 桌面壳窗口标题栏和评审窗口标题栏
- **布局**　正式 32 px 标题栏内把现有 Mixcat 标志放在 16 px 正方形位，与产品名平行对齐，间隔 8 px。评审窗可用 20 px 位，旁边保留「Mixcat 设计评审」。
- **按钮与操作**　标志随标题表达身份。回项目列表使用现有项目按钮并保留导航保护。若之后让标志承担导航动作，交互名用「返回项目列表」并有至少 32 px 按钮区。
- **样式**　继续使用 Mixcat 自有标志。浅色、深色、紫色用能保持轮廓对比度的版本，图片位与文字色随现有主题变量变化。没有变化的图像保持同样占位。
- **动效**　主题切换时固定尺寸直接更新标志版本。标志静止呈现，键盘焦点只由实际导航按钮承接。
- **验收**　三主题逐一切换并打开、缩放评审窗。产品名字和标志可读，切换时不挤窗口按钮，Tab 顺序与实际导航一致。

#### 015 modal

**模态框与危险确认** · 接入 · [免费注册表源码](https://www.boardui.com/r/modal.json)

- **BoardUI 原样**　黑色 70% 遮罩上居中放 400/480/640/800px 圆角卡，标题、说明和可滚正文分区，页脚靠右。危险款有 40px 圆形警示图标、取消和危险确认，面板以 300ms 缩放淡入。
- **Mixcat 页面**　项目 → 工作流 → 重置工作流，及项目列表 → 新建项目
- **布局**　复用 Dialog，重置宽 480px、新建宽 640px，边缘留 24px。标题、可滚正文与固定页脚分开，正文点名项目和重置范围，错误在页脚上方。
- **按钮与操作**　右下「取消」与「确认重置」，默认聚焦取消，Escape 走取消。提交中显示「重置中…」并锁定重复触发，运行保护以现有原因门控。新建沿用「创建项目」。
- **样式**　侧栏表面、1px 主题分隔线、16px 圆角，警告用主题警告底，确认用主题危险色，保留 2px 焦点环。
- **动效**　面板 160ms 淡入及上移 4px，遮罩同步淡变。减少动态时直接切换。
- **验收**　空闲项目按 Escape 后记录不变并返回按钮，忙碌时按钮旁可读保护原因。模拟提交失败后原框保留错误。

#### 016 drawer

**侧边或底部抽屉** · 接入 · [免费注册表源码](https://www.boardui.com/r/drawer.json)
