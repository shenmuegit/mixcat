# Mixcat 会话节点工作台扩展

归档目录：`docs/design/`。

日期：2026-10-19。状态：当前会话功能专项设计；完整功能清单及实现状态见 [客户端功能设计](2026-10-19-mixcat-client-functional-design.md)。暂停与启用遵循 [节点状态与暂停覆盖](2026-10-19-node-controls.md)，不引入额外全局控制锁。

本文的已有实现与验证描述保留原型阶段范围，客户端原型归档于 [prototypes/desktop](../../prototypes/desktop/README.md)。根目录正式开发版的当前实现、实际证据和未验证范围统一见 [交付矩阵](2026-10-20-delivery-status.md)；八项任务及最终独立整体复核已通过。

用户已确定继续使用独立 Mixcat 桌面应用，接入对应浏览器、文件及设计图面板。本轮按用户提出的十三项功能扩展现有基础；工作流 MCP 的新工具签名、条件选择规则和消息调用约定单独讨论。

## 交互与节点

- 画布右键创建节点；节点右键创建关联节点。键盘也可进入菜单。
- 创建表单选择名称、具体模型、已安装插件和技能；模型选择器不提供“原生默认”选项。候选来自实际原生能力目录，已保存但当前未发现的模型仍可选择；目录读取中或为空时显示提示和刷新入口，不伪造可用性。选择表示激活偏好，不撤销其他原生能力。
- 节点配置和创建表单移除计划 ID 编辑、冗余能力标题及 MCP/hooks 状态与信任区，模型下方接技能、插件和协作工具。已有计划 ID 随节点配置保存，目录错误仍显示，刷新入口位于 Skills 标题旁。
- 关联节点创建时同时保存有向关联边和自然语言条件；可以编辑条件。关联边与历史交接线是独立数据；本轮不执行条件表达式、不制定自动路由策略。
- 所有原生节点的启动和恢复目录固定为所属项目目录。

## 原生会话与自由消息

- 任意节点可以接收用户文本和原生支持的附件，不要求 summary/verdict 或固定成果格式。
- 同节点消息按序排队，原生 turn 成功即为本次消息执行成功；无需调用工作流 MCP 才能正常回答。节点保留自己的 thread，上下文由 Codex 持久保存。
- 新输入在执行前持久化。用户输入和其他节点交接显示在右侧并注明来源；当前节点回复及工具活动在左侧。
- 保留原始 native item 和完成状态，展示工具开始、完成、命令、文件改动、图片、计划等，未知类型可以查看原始内容，不静默丢弃。
- 项目时间线合并所有节点的同一份会话记录，按时间及稳定序号排序，明确归属节点。原生历史补齐以 thread/read 为依据，缺失原始时间不伪造。

## 能力与侧栏

当前已实现网页展示及用户操作、项目文件/图片/PDF/HTML 预览与节点归属；Agent 内嵌浏览器操作工具桥、MCP App UI 双向交互桥仍未实现。以下关于宿主承载的要求是能力目标，不表示所有官方桌面功能已接通。

- 移除 Mixcat 强制 read-only、never 和自动拒绝所有审批的行为；将原生审批、问题和 elicitation 交给用户响应。保留身份、路径、IPC 以及原生权限边界，不把完整能力解释为自动批准任何操作。
- 模型及选中 skills/plugins 注入实际原生 thread/turn，项目内运行数据与登录信息保持原路径。
- 已有节点配置优先显示显式模型选择；为空时回显该节点当前 Thread 最近一次已知的实际模型，并在保存配置时提交该模型。没有匹配的执行记录才显示选择提示，不根据目录默认项推断历史选择。
- 配置能力目录只读取模型、技能和插件及其发现错误，与会话级 MCP/hooks 运行状态查询分开。打开或刷新配置不恢复 Thread、不启动 Turn、不改变节点状态；已有原生会话在实际派发时按原路径恢复。显式信任与模板配置仍可核对所需运行状态。
- app-server 提供事件和资源，官方桌面侧栏本身不随引擎提供。Mixcat 宿主负责网页实例、节点归属、文件/图片预览和插件 UI 承载。网页不能访问主应用 IPC。
- 浏览器展示、Agent 浏览器操作、MCP App UI 各自单独验收；插件需要自己的服务、账号或宿主时如实显示可用性，不能把资源链接当作完整编辑器。

## 数据兼容

新增节点 model/skills/plugins、关联 edges、原始 conversation entries；保留旧 tasks、handoffs、artifacts 和 threadId。旧任务可还原已知输入/输出，已有原生会话可以补齐历史。历史交接不能自动迁移为条件边。

采用项目 SQLite 版本迁移与事务，不清空现有项目。所有新增日志、测试、缓存、附件和浏览器配置均保存在所属项目内部。

## 验收

右键两个入口、创建配置实际传给原生调用、条件保存与重启恢复、任意节点发消息/排队、普通回答成功、输入输出来源、完整项目时间线、原生工具结束状态、审批请求应答、历史迁移无重复及上下文保持、网页隔离和项目内文件预览。桌面实际操作验收与真实原生能力验证分别记录，不以模拟测试替代。
