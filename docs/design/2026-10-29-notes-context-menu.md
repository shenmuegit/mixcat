# 笔记节点菜单精简

关联 Issue #122；审查基线 `d3dab394d9cf461ec513f795cee20496dec75a5f`。

用户要求删除截图中的脑图选中节点常驻操作条，以及正文下方的“关联笔记”区域，节点右键仅提供新建笔记和删除。

- 移除两个区域的渲染及专属状态、样式。该调整是界面入口变更，不删除已存储的笔记关联。
- 节点菜单只含“新建笔记”和“删除”。新建调用已有创建操作，在右键目标下建立子笔记并打开编辑；删除调用已有子树回收确认，取消不产生变更。
- 右键作用于被点击的节点。ContextMenu/Shift+F10 提供键盘等价入口；方向键、Home/End 导航菜单，Escape 关闭并恢复节点焦点。
- 点击外部、移动画布、滚动、窗口变化或离开笔记时关闭菜单；菜单不越过可用窗口边界。挂起写入及已失效目标不能触发操作。
- 复用当前菜单样式与笔记领域操作。根级新建入口、脑图拖动和连接、正文编辑与草稿保护继续由现有实现承担。

验收通过实际 Electron 的右键/键盘、创建、删除取消/确认、恢复、不同打开/选中目标、菜单关闭/边界及原文档草稿回归完成；再运行类型检查、构建、完整测试和 Standards/Spec 双轴审查，合并后重启实际客户端。
